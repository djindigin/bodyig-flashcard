# bodyig-flashcard 藏语单词卡系统

[bodyig-flashcard](https://djindigin.github.io/bodyig-flashcard/)一个专为藏语学习打造的现代化、零安装网页端单词记忆系统。系统内置了仿 **FSRS（Free Spaced Repetition Scheduler）** 智能间隔重复算法，支持多词书独立管理、本地音频文件夹绑定、详细的数据状态追踪以及极致清爽的排版设计。

## 核心功能特色

1. **智能记忆调度（FSRS 算法）**

   * 采用科学的记忆衰减曲线模型，通过稳定度 $S$（Stability）与难度 $D$（Difficulty）动态计算复习间隔。

   * 支持 **🔴 不认识 / 🟡 模糊 / 🟢 认识** 三按键评级，自动将到期卡片优先推送至队列，告别机械死记硬背。

2. **多词书隔离与本地持久化**

   * 支持内置词书与自定义上传 Excel/CSV 词书自由切换。

   * 所有学习记录、熟练度及算法状态均保存在浏览器的 `localStorage` 中，即使关闭浏览器或隔天打开，进度依然完美保留。

3. **音频文件夹一键绑定**

   * 支持直接上传整个本地音频文件夹。

   * 系统通过卡片第四列的音频编号（如 `001`）与文件名（如 `001.mp3` 或 `001`）自动建立精准映射，实现自动播放音频的单词卡片。

4. **精致规范的排版设计**

   * **正面**：聚焦纯净的藏文字符与中心发音按钮，支持空格键快速翻转。

   * **背面**：采用左对齐流式排列，依次呈现藏文、中文释义、词性标签、来源、五度发音、威利转写、例句及动态扩展列。

   * 左上角配备极简的圆形纯符号 `🔊` 音频按钮，右上角实时展示 Anki 风格的熟练度圆点。

## 内置词书与音频说明

系统设计了默认的内置词书与音频通道：

1. **内置词书 (`words.json`)**

   * 系统在初始化时会自动尝试从根目录下请求加载 `words.json` 文件作为默认词书（显示名称为“默认内置词书”）。

   * 该文件包含了开发者预设好的一批基础藏语词汇数据，格式与自定义表格完全一致。

2. **内置音频目录 (`clips/`)**

   * 对于内置词书中的单词，系统默认会去同级目录下的 **`clips/` 文件夹** 中寻找对应的音频文件（例如音频编号为 `001` 的单词，系统会自动请求 `clips/001.mp3`）。

   * 对于一个单词多段音频，可在索引格内填入多个编号，以**`,`** 间隔，系统将依次全部播放

## 表格导入格式说明与示例

如果您想导入自定义的 Excel（`.xlsx`）或 CSV（`.csv`）词书表格，请确保表格**第一行为标题，从左到右依次对应前 8 列**：

| 列序 | 字段名建议 | 说明 | 
 | ----- | ----- | ----- | 
| **第 1 列** | 藏文 | 核心藏文字符（显示在正面及背面顶部） | 
| **第 2 列** | 中文释义 | 单词的中文翻译 | 
| **第 3 列** | 词性 | 词性标签（如 名词、动词等，带精美色块徽章） | 
| **第 4 列** | 音频序号 | 与音频文件夹中文件名相对应的编号（如 `001` 或 `word_01`）；可填入多个编号，以**`,`** 分隔 | 
| **第 5 列** | 来源 | 词汇来源出处说明 | 
| **第 6 列** | 五度标记法 | 发音调值或五度音调提示 | 
| **第 7 列** | 威利转写 (Wylie) | 藏文的拉丁字母转写 | 
| **第 8 列** | 例句 | 相关藏语例句及说明 | 
| **第 9 列及以后** | 扩展列（可选） | 任意自定义字段（如语法解析、备注等，系统会自动全部渲染） |

## 音频切分工具的用法与建议

如果您有一整段包含多个单词的长音频，并希望将其高效切分成独立的音频文件供系统使用，可以通过以下工具和替代方案来处理：

### 1. Colab 在线脚本用法 (`split_audio.ipynb`)

* **访问地址**：[Google Colab 脚本链接](https://colab.research.google.com/drive/1DnJ4PpBeF-I3-y8jRrn6keQB_d0ntrbE?usp=sharing&utm_source=gemini)

* **核心功能**：该 Notebook 提供了自动化切分逻辑，能够根据时间戳或静音片段，将长音频批量切片并命名为与表格第 4 列一致的编号（如 `001.mp3`, `002.mp3`）。

* **使用步骤**：

  1. 点击上方链接打开 Colab 页面。

  2. 依次运行 Notebook 中的代码块（`Runtime -> Run all`）

  3. 上传音频文件

  4. 运行结束后，自动下载生成的音频文件夹压缩包，解压后在藏语单词卡页面点击 **🎵 导入当前音频夹** 即可。

### 2. 针对无法使用 Google Colab 地区用户的替代方案

如果您身处的地区无法稳定访问 Google Colab，可以通过以下几种便捷的方式来切分音频：

* **方案 A：在本地电脑运行 Python 脚本**

  * 将 Colab 中的源码或核心逻辑下载到本地，在本地安装 Python、`ffmpeg` 以及 `pydub` 库：

    ```
    pip install pydub
    # 确保系统已配置并安装 ffmpeg
    
    ```

  * 编写或运行本地脚本进行批量切片，并将输出的 mp3 放入本地文件夹。

* **方案 B：使用专业的音频剪辑软件（如 Audacity / Adobe Audition）**

  * 将长音频导入免费开源软件 **Audacity**。

  * 利用“标签页/静音检测”或手动添加标签，将长音频分割成独立的片段。

  * 使用“多重导出（Export Multiple）”功能，将文件名严格命名为与表格第 4 列（音频序号）完全一致的名称（例如 `001.mp3`, `002.mp3`）。

* **方案 C：使用轻量化命令行工具 (FFmpeg)**

  * 如果您熟悉命令行，可以直接使用 `ffmpeg` 根据起止时间快速切片：

    ```
    ffmpeg -i input.mp3 -ss 00:00:10 -to 00:00:15 001.mp3
    
    ```

## 快速使用指南

1. **打开系统**：直接在任意现代浏览器中访问 [djindigin.github.io/bodyig-flashcard](https://djindigin.github.io/bodyig-flashcard/) 。

2. **选择词书**：系统将默认加载内置词书，您也可以通过顶部工具栏随时切换到自定义导入的词书。

3. **导入新词书**：点击 **📁 导入新词书** 按钮，选择符合上述表格格式的 `.xlsx` 或 `.csv` 表格。

4. **绑定音频**：点击 **🎵 导入当前音频夹** 按钮，选中存放该词书对应 `.mp3` 文件的整个本地文件夹（如果是内置词书且已配置 `clips/` 目录则可直接发音）。

5. **开始学习**：

   * **查看正面**：认读藏文字符，点击发音按钮或直接按 `Space` 键翻转卡片。

   * **查看背面**：核对左对齐的各项详细数据，点击左上角圆形 `🔊` 按钮可重复听发音。

   * **打分反馈**：根据掌握情况点击底部的 **不认识 (1)**、**模糊 (2)** 或 **认识 (3)**（也可用键盘数字键 `1`、`2`、`3` 快捷操作）。

6. **查看统计**：点击顶部 **📊 统计** 按钮，可随时查看本次会话的答题频次分布图与全部词汇的总体熟练度状态。

* **存储引擎**：HTML5 LocalStorage
